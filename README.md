# Creazy Shootan! — прототип (Godot 4.7)

Грати онлайн: https://randomizer2223.github.io/creazy-shootan/play/

## Як запустити у браузері
1. Встанови Godot 4.7.x (Standard, не .NET): https://godotengine.org/download
2. Відкрий Godot → Import → вибери файл `project.godot` з цієї папки.
3. Editor → Manage Export Templates → Download and Install (один раз).
4. У правому верхньому куті натисни іконку **Remote Deploy / Run in Browser** (HTML5) — гра відкриється в браузері.
   Або просто F5 — запуск у вікні на ПК.

## Керування
A/D — рух · W/Пробіл — стрибок · S (або A+D) — копати
Мишка — приціл (або стрілки вгору/вниз) · ЛКМ/J — постріл
ПКМ/K/Shift — трос (ще раз — відпустити) · W/S на тросі — коротше/довше
Зміна зброї: колесо миші, Q/E, або цифри 1-9 (панель зброї внизу екрана)
Підібрана зброя одразу береться в руки · Esc — пауза · H — підказка

## Що вже є
- Повністю руйнівна попіксельна мапа, 10 мап + своя картинка як мапа
- Базука, граната, банан-бомба (розпадається на 8), дробовик, мінігун, землемет (створює територію)
- Ящики зі зброєю й аптечки, кулдауни, 5 режимів перезарядки
- Трос (ninja rope), копання, боти 3 рівнів

## Далі
Редактор мап зі збереженням, сенсорне керування для мобільних, онлайн / Bluetooth.

## Структура
scripts/sprites.gd — піксель-арт (ворм, іконки зброї) · pixel_font.gd — піксельний шрифт
scripts/terrain.gd — руйнівна мапа · mapgen.gd — мапи · worm.gd — ворм і трос
weapons.gd — вся зброя (легко додавати) · bot_ai.gd — боти · game.gd — матч
